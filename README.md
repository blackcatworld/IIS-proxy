# IIS-proxy
Install HTTP Redirections
Open Server Manager

Click Manage → Add Roles and Features

Go through:

Role-based or feature-based

Select your server

Under Server Roles → Web Server (IIS):

Expand Web Server

Expand Common HTTP Features

Check:
✔ HTTP Redirect

Click Next → Install

Restart IIS if needed
